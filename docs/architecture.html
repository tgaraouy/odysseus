Architecture

A self-hosted AI agent that uses tools to turn your labs, wearables, and notes into a tamper-evident, confidence-graded health record. This page is the visual companion to docs/ARCHITECTURE.md — same content, with the diagrams.

01The agent loop

An agent is a model placed in a control loop that can act, not just reply. A tool is a function it can call (read_file, web_search, your health_log_journal). The loop is the cycle below.

Why it matters

  1. Step 3 is the whole point. The one thing separating an agent from a chatbot is that the model sees the result of its own action and decides again. Prompt→reply once becomes observe→re-decide. Everything called "agentic" is built on that single addition.
  2. Why it's the topic now (inferred, not reported — past my knowledge cutoff). The loop is an old idea; its prerequisites crossed usable thresholds together — reliable tool-calling, multi-step instruction-following that holds across turns, and long-enough context to accumulate observations. A technique becomes "the topic" when its prerequisites stop being the bottleneck.
  3. What it buys us. It's the only reason Touf is more than a chatbot — it chains retrieve→compute→write in one request. "Log a baseline" was a loop: read ledger → pull WHOOP → write journal → confirm. It runs n-of-1 analysis over your data and lets you use the record by talking to it.
  4. Its power and its risk are the same thing. Every observation fed back at step 3 is a fresh chance for injected text to hijack the next action. The loop is why F-1 (fencing tool output) and the sandbox exist — capability and attack surface are inseparable.

02The running system

Each box is a container (docker-compose.yml); the host runs the LLMs and the health bridge outside Docker.

03The record — bronze → silver → gold

Every fact is appended to a hash-chained ledger (each block carries the previous block's hash, so tampering is detectable) and graded by how trustworthy it is.

Confidence taxonomy — every fact is graded

MEASURED OBSERVED INFERRED CLAIMED

MEASURED = directly captured (a lab, a WHOOP reading) · OBSERVED = credible secondhand (a clinician note) · INFERRED = model/expert judgment · CLAIMED = your own self-report.

04Security — the loop is the surface

Because you're the single admin, the agent runs with every tool. So the defense rests on two pillars: fencing (untrusted text wrapped as data, not instructions) and sandboxing (even a fooled model can't reach secrets, network, or data).

The principle: the same step-3 feedback that makes the loop powerful is the injection surface. F-1 fences tool output at that exact point; the sandbox removes the payoff for the worst sinks (bash/python). Power and risk are one mechanism.
